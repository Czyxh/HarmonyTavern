# 设置选择器与帮助入口（2026-11-02）

## 当前行为

- 辅助模型设置保持在设置首页「模型与连接」分类，与服务商管理同级。
- 展开选择内置 Qwen 或服务商管理内保存的模型；服务商需有可用密钥。去重当前模型与模型列表，支持搜索和分批显示长列表。
- 「前往服务商管理添加模型」使用现有服务商管理页面。辅助页不再提供重复的地址、协议、模型和密钥创建表单。按用户最新要求移除内置助手更换密钥入口及输入表单，保留已有凭据。
- 选择辅助模型不会改变聊天主服务商或轮换密钥。请求读取实时服务商配置，保留原生服务商、区域与自定义协议，显式使用对应密钥；删除密钥后给出可操作错误。
- 旧独立辅助配置仍保留并可由后端路由读取，不做破坏性迁移。界面提示重新选择服务商管理中的模型。
- SettingsPicker 统一人设插入位置、消息角色、推理强度、故事选项数、群聊回复方式和发言者、辅助模型及帮助主题；使用同一玻璃样式、选中勾选和展开动画，支持减少动态效果。
- 移除设置首页运行诊断与维护及运行日志入口，以及首页调试方法。保留真实初始化、局域网配对功能及后端日志能力。
- 新增「帮助与关于」分类：使用帮助、反馈与建议、关于 HarmonyTavern、赞助开发者。帮助含本地说明，关于读取实际安装版本；反馈与赞助明确提示尚未开放，按钮禁用，没有接入提交或支付服务。
