# 刷新工具栏与模型面板修正

本轮针对用户反馈的刷新样式、按下反馈、预设新建位置，以及模型面板布局、滚动和返回异常。

## 改动

- 新增共用 `HeaderAction`：44vp 圆球、统一玻璃材质/边框/高光，立即按下反馈；刷新图标有短旋转，实际请求期间显示进度，阻止重复点击。减少动态效果时跳过装饰旋转。刷新不人为延迟业务结果，不用固定延时假装请求仍在进行。
- 应用设置、用户设定、预设、角色、备份、技能、同步、世界书等页面刷新入口接入同一组件；模型列表重新获取和服务商管理刷新也使用它。自动刷新开关保留原有含义。
- 预设工具栏右侧顺序统一为“刷新、＋”，创建按钮使用加号圆球；角色新建同步采用相同工具按钮。预设创建仍是本地草稿，按保存前不写入预设文件。
- 用户设定顶部刷新补接人设表单重读，而非只刷新其他用户档案；异步读结果带序号防止旧响应覆盖，退出页面后停止更新界面。应用设置刷新等待当前表单保存结束。
- 模型内嵌面板移除额外 Navigation 和内层安全区扩展，保留独立的服务商列表/详情状态。系统返回先从详情回列表，再收起弹层，聊天页面保留。外侧点击仍可收起整个面板。
- 视图直接读取 `embeddedDetail` 状态，不通过按值 Builder 参数保留旧详情。详情固定顶部标签栏，只有正文滚动；进入服务商/切换标签时重置滚动位置。
