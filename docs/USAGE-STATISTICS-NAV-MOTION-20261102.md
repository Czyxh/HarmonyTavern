# 使用统计与导航收起回弹（2026-11-02）

## 用户要求与设计基准

在设置「模型与连接」中新增使用统计，按用户长图实现时间分段、活动热力图、总览、模型排行、Token 六项、来源及 Token 消耗排行。随后用户提供 5.16 秒导航视频，要求进入二级页收起、返回跳回的非线性动画。

本轮使用 OpenDesign，并提取现有设计基准至 opendesign/design-systems/harmonytavern/SKILL.md，复用纸张/主题色、玻璃顶栏、PageSurface、HeaderAction 与 JellyTabBar。保留用户确认的导航材质和设置结构。

## 真实统计链路

- 设置新增「使用统计」入口，原设置路由保留。
- get_native_usage_statistics 提供全部、近30天、近12个月统计；Rust 在后台线程逐行读取当前资料目录内的聊天/群聊 JSONL 及本地请求账本。
- 总览和热力图基于仍保留的非系统、非空聊天消息。初始开场白也属于现存消息；未知日期只计入全部，不猜日期。日期使用设备当前 UTC 偏移；近12个月按日历月份计算。
- 活跃会话按该范围内有消息的会话去重；模型回复排行仅按消息中实际保存的模型名统计。历史缺少模型名明确显示未记录，不用当前模型倒填。总览名称为「已记录的模型」。
- 在 ChatCompletionService 的非流式、流式和 Agent 共用请求层增加 UsageObserver，覆盖聊天、群聊、剧情选项、上下文精简、状态生成、Agent 和其他后台请求。使用用途标记和请求关联键，发送前移除内部标记，不传给服务商。
- 请求账本保存于 `<data_root>/default-user/harmony-usage/requests.jsonl`，记录随机事件 ID、关联键、时间、模型/来源、用途、服务商返回计数及完成标志；不保存提示词、回复正文、密钥或端点。写失败不影响聊天，记录日志。
- 流式计数为累计快照，合并覆盖而非反复相加；同一事件只入账一次。取消/错误时保留已经返回的真实计数并标为部分完成，没有返回计数则未知。
- 缓存解析覆盖 OpenAI/Responses 的 token details、Claude cache read 与 Gemini cached content。缓存为输入子集，不重复加入总量；Claude 输入包含 cache creation/read。无总量时只可由已报告输入与输出相加，不用本地 tokenizer 估账。
- 新聊天/群聊回复保存冻结的实际请求模型与关联键。统计仅在本地账本确实包含对应关联时跳过消息内用量；导入或只恢复聊天、账本丢失时回退消息已有真实用量，防止盲信布尔标记漏算。
- 平均值仅使用有总量的聊天请求/可回填历史回复；缓存率仅使用同时报告缓存和输入的请求，并在页面说明分母。未提供/历史缺失为「—」，已知 0 为 0。删除聊天不删除独立请求账本；历史没有保存的后台用量无法补回。

## 页面与交互

- 三段时间选择影响概览、排行和 Token 统计；全部范围的热力图单独显示最近12个月，活跃日/连续天数与该图窗口一致。
- 热力图按周分列、支持横滑和点选日期；44vp 前后日按钮提供等价查看方式。2列数字卡、模型/来源进度条排行、完整空态、读取失败重试和顶栏刷新。
- 请求版本防止切范围/离开页面后旧结果覆盖新内容。加载过程中不混显旧范围数据。
- 统计页局部裁剪原生分段背板，避免直角阴影露出；页面内容顶间距由104收紧到84vp，仅此页生效。热力图明确提示横滑。

## 导航动画

- 参考视频提取于 build/nav-motion-reference/，无外传。进入二级页时以240ms加速曲线向底部缩小退出；返回使用 springMotion(0.42,0.76,0.08) 向上弹回。此为项目动效参数，不声称官方规定或逐帧等同参考。
- 以底部中心为缩放锚点；位移/缩放/透明度为图形变换，不逐帧修改页面布局。新目标直接接管现有显隐动画，无延迟定时器锁。
- 逻辑 dockMode 与退场用 dockPresentationMode 分离，收起过程中保留原控件及材质，避免聊天输入突然替换为主页导航或额外叠加底板；隐藏时立即停止命中和读屏。
- 减少动态效果跳过弹跳，使用即时状态；宽屏底部导航仍按现有布局隐藏。
