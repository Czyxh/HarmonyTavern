## 本轮实现

检查发现，聊天页仅对两个顶部入口单独监听挤压脉冲，其他 `HeaderAction` 圆球没有同样的挤压反馈。

- 在共享 `HeaderAction` 内按来源 marker 匹配脉冲，加入挤压和回稳，使首页创建等同类入口复用相同行为。
- 同时观察来源 ID 和脉冲状态，快速切换来源时只变形当前入口；空 marker 不参与。
- Touch Down 即时缩小内部内容，Up/Cancel 回稳；外层锚点不受按压内容缩放影响。既有透明度反馈继续有效。
- 开启减少动态效果时立即清除挤压和内容缩放。
- 删除 `ChatPage` 中两个入口重复的挤压状态和外层缩放，避免两次形变。
- 继续复用已经统一的原生和兼容玻璃材质，没有重新调整玻璃配方。
