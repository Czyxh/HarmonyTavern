# API 26 UI 修复与材质验证（2026-11-01）

> 后续用户调整了外观要求：次级面板背景应采用普通模糊以保证可读，液态效果集中于导航和按钮。SystemMaterialBackdrop 因此已从最终版本撤回；下文水滴背板实验为历史记录。当前行为与安装包见 [LIBRARY-CHAT-INTEGRATION-20261101.md](LIBRARY-CHAT-INTEGRATION-20261101.md)。

## 修复

- 修复进入聊天时 Builder 直接构造组件、丢失页面上下文的问题；Index 使用捕获页面上下文的 Builder 包装调用 ChatDock。
- 导航内容在原生 TabBar 可用高度内居中，去掉重复的上下留白。聊天输入和发送按钮同步修复，多行高度计入原生留白。
- 官方材质对象缓存复用；API 22 仍由运行时检查和动态导入保护。

## 官方文档与水滴承载

华为[开启沉浸光感](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/arkts-immersive-light-sense-enable)（更新于 2026-10-26）说明：普通组件仅在 Navigation/NavDestination 标题栏或横向 Tabs 的底部 TabBar 中生效；指定 Popup、菜单、弹窗接口可在全页面生效。[官方 uiMaterial API](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/reference/apis-arkui/arkts-apis-uimaterial.md)定义 ImmersiveMaterial、ULTRA_THIN、Material.empty 和设备材质档位。系统光感配置也影响实际表现。

实测普通 Column 直接设置 systemMaterial 没有背景滤镜；整个水滴使用 barFloatingStyle 则出现多余胶囊弧边。这两种方案均已撤回。

最终 SystemMaterialBackdrop 使用非悬浮的横向底部 TabBar 场景，通过 barModifier.systemMaterial(Material.empty) 关闭默认背板，清空原生背景色与模糊；仅内部自定义层使用 systemMaterial(ImmersiveMaterial)。模拟器中背景采样和模糊已出现，没有重复胶囊弧边。外层保留 LiquidSurface 路径与可打断动画，输入由原有前景层处理。自定义层补偿当前原生项横向 12vp、纵向 4vp 留白；其他设备形态尚未验收。

**验收边界：官方材质接入、背景采样和消除重复轮廓已验证；用户要求的明显水滴曲面光线扭曲尚未完成视觉验收。clipShape 裁剪不等同于将任意贝塞尔路径传给原生光学模型。不能将模糊、高光或编译成功描述为完整水滴折射已完成。**
