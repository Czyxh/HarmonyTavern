# 内置 Qwen 联网助手与滑块按压层修正（2026-11-02）

## Qwen 接入完成

承接工程内已有、尚未完成设备配置的 `BuiltinAssistant` 草稿，固定使用硅基流动 `https://api.siliconflow.cn/v1` 的 `Qwen/Qwen3.5-4B`，用于服务商配置助手的结构化整理，与用户聊天模型独立。这是应用内置入口的联网模型，不是设备离线模型。

- 使用用户本轮提供的密钥，官方模型列表请求返回 200，确认精确模型 ID 可用。
- 最小实际生成请求返回 200 和 `{"ok":true}`，用量 28 tokens；采用非流式、关闭思考和 JSON 输出。
- 通过应用现有“保存助手密钥”入口写入模拟器应用私有后端密钥库。没有将密钥写入源码、资源、文档或安装包配置；源码扫描未发现本轮密钥。
- 助手通过独立 `secret_id` 取密钥，保存时保留原有自定义聊天服务商的活跃密钥。未更改默认聊天模型。
- 首次调用沿用既有端点授权，按用户本轮明确指定的硅基流动端点完成授权。
- 应用内真实“Qwen 整理”成功生成可编辑草稿：示例地址从 chat/completions 归一化为基础地址，协议为 OpenAI Chat Completions。未提交示例服务商配置，未创建或发送聊天消息。
- 没有密钥或正在保存时禁用 Qwen 整理，避免未配置请求。原始输入和其中密钥仍由本机解析，只把地址、模型、协议发给助手。
- 覆盖安装后重新打开助手仍显示“已配置”。手机包不携带模拟器私有密钥，新设备需要在助手界面保存自己的密钥。

## 滑块按压层

原生材质的 `Tabs` 以单个自定义 TabBar 内容承载整排按钮，按钮同时处于原生 TabBar 的交互层内；内层可见内容、原生宿主和外沿的边界不同，存在叠加按压或悬停底色的风险。

- 原生 Tabs 继续渲染官方玻璃底座、镜片和光场，但不再接收触摸，也不暴露重复无障碍子树。
- 真实按钮和拖动手势放在独立覆盖层。位置来自实际 tray 与宿主的全局区域差值，避免硬编码屏幕坐标。
- 自绘按钮明确关闭系统 hover，保留文字透明度反馈、镜片形变和光场反馈。
- 文字分段的宿主保留上下各 4vp，实际内层高 40vp；修正独立按钮仍为 44vp 的溢出。实测 tray `[119,717][1161,857]`，首按钮 `[119,717][640,857]`，上下边界一致。
- 主导航、资料库、服务商和其他共用 JellyTabBar 入口复用该修正；保留 API22 兼容路径和减少动态效果。
