# 简约冒险侧栏与资料编辑 · 2026-11-02

## 本轮交付

- 创造模式使用当前应用 startIcon，默认贴右侧露小角。点击旋转一周并展开窄胶囊，再点收回；减少动态效果时跳过旋转和形变。
- 工具栏提供任务、人物关系、位置与状态、物品、设置。详情按内容高度收缩为小浮层，无整屏暗色遮罩；刷新/设置/关闭为 32vp 图标。生成中刷新替换为取消，应用提交阶段不可取消。
- 跟随智感握持或固定侧边；展开期间冻结方向，详情沿用工具栏方向。
- 未初始化时才显示教学和用量提示；已有快照不显示长空态说明或依据注释。真实未知值仍显示未确认，旧状态保留待确认标记。刷新/读取失败保留同会话旧快照，避免教学提示闪现；不跨会话复用。
- 聊天内故事与聊天模式移除名称、背景、风格、补充规则；新建会话仍可填写。布局示例移除。
- 每段创造模式可选状态栏模型、辅助自动/主回复内联/仅手动更新。辅助模型复用服务商已保存模型与密钥，不切换主聊天模型。
- 默认自动模式在完整正文保存后单独提取状态，只发送有界参考、有效旧快照和近期剧情；不为主模型增加状态协议与快照。辅助服务仍计费，原主剧情使用世界书的用量仍存在。
- 任务与关系加入校验和持久化；不凭形容词推算好感度或擅自填满血量。上下文会截取，不能保证遗漏信息的精确还原。
- 角色加号互通新建与 PNG/JSON/粘贴导入，导入后进入完整编辑：人格、场景、开场白、备选开场白、示例、提示词、作者标签版本。修正清空旧字段、显示名误作存储键、重命名后更新旧键问题。导出走系统文件保存。
- 世界书支持搜索、条目标题、较长正文、次级关键词、顺序、概率及开关、增删、导出；保存保留未知字段和原概率语义。
