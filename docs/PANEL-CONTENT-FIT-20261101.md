# 展开面板按内容收紧（2026-11-01）

## 改动

- 管理式 ChatPanel 不再将屏幕比例直接当作固定高度。分别测量标题、正文自然高度、底部操作区，将其合计回传给当前 OriginPanelState；原 heightRatio 只作为上限。
- OriginPanel 按实际内容和可用屏幕高度取较小值。短面板收紧，长内容继续在内部 Scroll 滚动；窗口/键盘改变仍走原布局更新及可打断动画。
- 浮动面板已由外层避开系统安全区，因此正文末尾只留 20vp、底部操作区 12vp，不重复叠加系统底部安全区。
- 接入聊天的会话选择、编辑、精简、创造模式/背包、生成设置、搜索、摘要、上下文，以及首页会话操作、工具页快照确认。独立服务商编辑工作台保留其原屏幕布局。
- 三项菜单仍用已有内容测量，不受此变更影响。快速关闭再展开保留当前有效测量，完全关闭后新开再重新测量。
- 不改磨砂、颜色、正文数据或原生协议；没有调用模型，也没有恢复设置或改动聊天。
